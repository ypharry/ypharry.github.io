# CV source workspace

The maintained CV source files are [`cv/CV_template.tex`](CV_template.tex) and [`cv/cv_style.cls`](cv_style.cls). The compiled public output is [`files/cv.pdf`](../files/cv.pdf).

The TeX source is compiled outside the tracked tree so auxiliary files such as `.aux`, `.log`, `.out`, `.fls`, `.fdb_latexmk`, and `.synctex.gz` are not committed. Only the source files, this README, and the final PDF belong in the repository.
